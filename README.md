# Doctor Appointment Terminal Application

A simple **terminal-based application** to manage doctor appointments. Built using **C++**, this app stores data in **text files** and allows users to schedule, view, and manage appointments through the terminal.

---

## Features

- Add new appointments with patient details  
- View all scheduled appointments  
- Search for appointments by patient name or date  
- Edit or delete existing appointments  
- Data stored persistently in **text files**
